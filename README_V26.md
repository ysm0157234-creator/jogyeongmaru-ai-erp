# v26 국립종자원 제출본을 한글 .hwp로 생성

## 요구사항

국립종자원에 올리는 파일은 **한글 `.hwp`**여야 한다(워드 아님). 기존에는 ZIP에
`.hwpx`(한글)와 `.docx`(워드 호환용)가 같이 들어가고 있었고, 실제 제출 형식인 `.hwp`는 없었다.

## 왜 어려운 문제였나

`.hwp`(HWP 5.x)는 OLE 복합문서 안에 자체 레코드 구조를 zlib으로 압축해 넣은 바이너리다.
**읽는 라이브러리는 있어도 쓰는 라이브러리가 없다.** 백지에서 만드는 건 불가능하다.

→ 해결: **실제 제출본을 템플릿으로 두고 내부 바이트를 고쳐 쓴다.**

## 구현 (`hwp_binary_service.py`, 신규)

### 1. 본문 레코드 파싱

`BodyText/Section0`을 zlib 해제하면 레코드가 연속으로 이어진다.
헤더 4바이트에 tagID(10비트) · level(10비트) · size(12비트)가 들어 있고,
size가 `0xFFF`면 뒤에 4바이트 실제 크기가 따라온다.
`HWPTAG_PARA_TEXT`(67) 레코드의 본문이 UTF-16LE 문자열이다.

### 2. 글자 수 정합성 (이게 핵심)

텍스트 길이가 바뀌면 두 곳을 같이 고쳐야 한다. 안 고치면 한글이 문서를 깨진 것으로 읽는다.

- 레코드 헤더의 **size** 필드
- 직전 `HWPTAG_PARA_HEADER`(66)의 **글자 수** 필드 (UTF-16 코드 유닛 기준으로 증감)

### 3. 스트림 크기 제약

OLE 스트림은 **원래 크기를 넘겨서 쓸 수 없다**(넘기려면 컨테이너 전체 재구성이 필요).
그래서 압축한 뒤 남는 만큼 `0x00`으로 채운다. zlib은 압축 스트림 뒤의 잉여 바이트를
무시하므로 안전하다.

```
본문: 재압축 8,919 ≤ 용량 12,647   (여유 3,728바이트 ≈ 한글 수천 자)
```

용량을 넘기면 명확한 오류를 내고 예비본 `.hwpx`로 자동 대체된다.

### 4. 사진 교체

품종 사진은 `BinData/BIN0005.bmp`(전체) · `BIN0006.bmp`(근접) 슬롯이다.
사진 BMP는 거의 압축이 되지 않아 용량이 빠듯하므로, 슬롯 용량에 들어갈 때까지
해상도를 단계적으로 낮춘다(1.0 → 0.92 → … → 0.25). 문서에 표시되는 크기는 별도로
기록되어 있어서 배치는 그대로고 해상도만 낮아진다.

### 5. 별지 설명 문단 배분

`.hwp`에서 문단을 새로 만들려면 레코드 묶음을 통째로 삽입해야 해서 위험하다.
대신 **템플릿의 고정 문단 슬롯에 나눠 담는다.**

- 품종 특성 설명: 4개 슬롯. 문장이 더 많으면 마지막 슬롯에 이어 붙인다.
- 육성과정 설명: 1개 슬롯.

### 6. 날짜 표식

서식의 자간(`2025년     5월     13일`)을 살려야 해서 통째로 치환할 수 없다.
숫자 자리만 표식으로 두고(`{{년}}년     {{월}}월     {{일}}일`) 숫자만 채운다.

## 템플릿

`app/templates/plant_import_report_template.hwp` (신규)

실제 제출본에서 회사·품종 데이터를 전부 표식으로 바꾼 것이다. 개인정보는 남아 있지 않다.

```
제거 확인: 황수영 / 조경마루 / 떡갈잎수국 / PIIHQ-I / 010-9377 / 29-25012016 / Hydrangea
표식 20종: {{대표자}} {{법인명칭}} {{주소}} {{주소_축약}} {{생년월일}} {{전화번호}}
          {{작물명}} {{학명}} {{품종명}} {{원산지}} {{종자업등록번호}} {{검역합격번호}}
          {{품종특성설명}}~{{품종특성설명4}} {{육성과정설명}} {{년}} {{월}} {{일}}
```

## ZIP 구성 변경

```
이전: 01_..._검토안.hwpx  +  01_..._호환용.docx
이후: 01_..._검토안.hwp                       ← 제출본
      (hwp 실패 시에만 .hwpx, 둘 다 실패 시에만 .docx)
```

워드는 제출 서식이 아니므로 정상 경로에서는 더 이상 넣지 않는다.

## 변경 파일

| 파일 | 내용 |
|---|---|
| `backend/app/services/hwp_binary_service.py` (신규) | HWP 5.x 레코드 파싱·텍스트 치환·글자수 보정·재압축·사진 교체 |
| `backend/app/templates/plant_import_report_template.hwp` (신규) | 실제 제출본에서 데이터를 표식으로 바꾼 템플릿 |
