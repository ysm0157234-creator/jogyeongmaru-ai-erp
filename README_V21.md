# v21.1 원본 Invoice·컬러 사진 우선

- Invoice 발췌본 생성을 제거했습니다.
- XLSX/XLSM은 원본 서식과 시트를 유지하고 Shipment Overview의 수량만 품종 행에 반영합니다.
- PDF는 원본 페이지를 유지하고 품종 행의 수량 숫자를 찾았을 때만 덮어씁니다. 찾지 못하면 원본 PDF를 그대로 첨부합니다.
- Serper 웹검색 결과의 공식·판매 페이지 이미지가 Wikimedia보다 먼저 표시됩니다.
- illustration, plate, drawing, herbarium, scan 등 흑백 도감 후보는 감점합니다.
- Wikimedia Commons는 보조 후보로만 사용합니다.
