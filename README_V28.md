# v28 국립종자원 신고 자동입력 (제출 직전까지)

ERP가 만든 ZIP을 그대로 써서 국립종자원 신고 화면을 자동으로 채운다.
**신고(제출) 버튼은 누르지 않는다.**

## 대상 시스템

| | |
|---|---|
| 사이트 | `https://www.seednet.go.kr` (국립종자원 종자민원서비스) |
| 신고 메뉴 | `/report/cvw/cvwAppMstList.do?appl_knd=30&appl_st_cd=30` |
| 로그인 | 아이디/비밀번호(클라이언트 RSA 암호화) 또는 공동인증서·금융인증서·행정전자서명 |
| 기타 | CSRF 토큰 사용 |

## 자동화하지 않는 것 (의도적)

| | 이유 |
|---|---|
| **로그인** | 아이디·비밀번호·인증서는 자동화가 대신 입력하지 않는다. 브라우저 창에서 사람이 직접 로그인한다. 세션은 저장해서 다음 실행 때 생략한다. |
| **신고(제출) 버튼** | 되돌릴 수 없는 행정 행위다. 값 입력과 첨부까지만 하고 브라우저를 열어둔 채 끝낸다. |

## 왜 2단계인가

신고 작성 폼은 로그인 안쪽이라 미리 볼 수 없다. 못 본 화면의 입력 항목을 추측해서
선택자를 짜면 거의 틀린다. 그래서 **실제 화면 구조를 먼저 뽑고**(1단계),
그것을 보고 입력 매핑을 만든 뒤(2단계) 자동 입력한다(3단계).

화면이 개편되면 1·2단계만 다시 하면 된다.

## 구성

```
automation/
  README.md                 사용법
  requirements.txt          playwright
  field_map.example.json    입력 매핑 서식
  seednet/
    config.py       URL·대기시간·세션 경로
    browser.py      브라우저 실행, 사람 로그인 대기, 세션 저장
    payload.py      ERP ZIP → 신고 입력값 + 첨부파일
    dump_form.py    1단계: 화면 구조 덤프 (라벨·name·id·select 옵션·iframe 포함)
    fill_report.py  3단계: 자동 입력 후 제출 직전 정지
```

## 검증 (실제 ZIP으로 확인)

```
ZIP 생성: 1,464,829 bytes
신고 입력값 13개 전부 추출, 비어 있는 항목 없음
첨부파일 인식: 신고서(.hwp) / 품종사진_전체 / 품종사진_근접
```

(검역합격증·인보이스는 Drive 연동이 있는 실제 실행에서 ZIP에 포함된다.)

## 남은 작업

1. `python -m seednet.dump_form` 실행 → 실제 신고 화면 구조 확보
2. 그 결과로 `field_map.json` 작성
3. 실제 신고 건으로 자동 입력 확인 (제출은 사람이)

## 주의

- 값이 빈 항목은 건너뛰고 목록으로 알려준다. 특히 **검역합격 발급번호**는
  Drive에서 검역합격증을 못 찾으면 빈 값이 된다.
- `.seednet-session.json`에는 로그인 쿠키가 들어 있어 `.gitignore`로 제외했다.
